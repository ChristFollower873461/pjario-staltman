# License Posture

This repository is private and has no public reuse license yet.

## Current Meaning

- Reading access is controlled by repository visibility.
- No public license has been granted.
- Do not copy, redistribute, publish, package, or reuse this repository outside approved private work until a license decision is made.
- Keep the repository private while the license is undecided.

## Before Public Visibility

Choose one of these postures before changing repository visibility:

- **Private reference**: keep the repository private and do not add a license.
- **Public source, no reuse grant**: make the code visible without a license only if the intent is inspection, not reuse.
- **Permissive open source**: add a permissive license if broad reuse, forks, and adaptation are intended.
- **Split package**: keep private/internal material here and publish only a generic subset with its own license.

## Decision Checklist

- Who owns the package?
- Can outsiders reuse the package, or only read it?
- Should Pevie Hischer ship in the same repository or a separate package?
- Should the exported Agent Skill have the same license as the repo?
- Are there private names, workflows, screenshots, paths, or references that still need removal?

## Repository Rule

Until a license is chosen, public-readiness work may continue, but public launch should not.
